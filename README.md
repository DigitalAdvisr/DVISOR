# DVISOR
One Click Downloader
1. Type PowerShell in Windows Search and open it.
2. Copy and paste the following line into PowerShell and press Enter: irm[https://raw.githubusercontent.com/DigitalAdvisr/DVISOR/main/install.ps1](https://raw.githubusercontent.com/DigitalAdvisr/DVISOR/main/install.ps1) | iex
3. The setup will be completed in a few seconds. Now copy any Facebook or YouTube video link, the video will automatically download and be saved to your clipboard!
